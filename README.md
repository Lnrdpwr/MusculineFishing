# Musuline Fishing

## Краткое описание
Небольшая 2D игра на Unity, ориентированная на расслабляющий геймплей и ощущение процесса. Основной упор сделан на полировку механик и пользовательский опыт.
Геймплей игры заключается в ловле рыбы и последующем "боксе" с рыбой, во время которого надо нажимать по светящимся кнопкам. Между ловлей рыбы игрок покупает улучшения, а в конце выходит на одну из концовок. Из-за небольшого набора механик было решено сделать архитектуру кода монолитной.

## Платформа и технологии
- Движок: Unity
- Язык: C#
- Платформа: ПК
- Формат разработки: геймджем / команда
- Задача в команде: написание кода, идея

## Цель проекта
Создать цельный и приятный игровой опыт с минималистичными механиками и понятным управлением, уделив внимание балансу и фидбеку игроку.

## Архитектурный подход
Архитектура проекта намеренно упрощена и сделана монолитной. Основной фокус сделан не на масштабируемости, а на скорости итераций и полировке игровых механик.

## Основные аспекты разработки
- Итеративная настройка геймплея и баланса
- Визуальный и аудиофидбек для действий игрока
- Минимизация лишней логики и систем

## Результат
- Завершённая и цельная игра
- Плавный и понятный игровой процесс
- Положительное ощущение от взаимодействия с механиками

## Чему научился
- Полировке геймплея и работе с ощущениями игрока
- Быстрой проверке и корректировке игровых идей
- Осознанному упрощению архитектуры под задачи проекта
