# Musculine Fishing

## Краткое описание

Небольшая 2D игра на Unity, разработанная в формате геймджема. Игра ориентирована на расслабляющий игровой процесс с акцентом на фидбек и ощущение от действий игрока.

Основной геймплей строится вокруг ловли рыбы и последующей тайминговой мини-игры в стиле бокса. Между ловлей рыбы игрок покупает улучшения в магазине, а в конце прохождения получает одну из нескольких концовок.

Проект был реализован с упрощённой архитектурой, оптимизированной под скорость разработки и итераций во время геймджема.

## Gameplay systems

В проекте реализованы следующие игровые системы:

* система ловли рыбы (по аналогии с механикой из Stardew Valley)
* тайминговая мини-игра "бокс с рыбой"
* система магазина и апгрейдов
* система кошелька (разделена на model и view)
* система мини-квестов
* система концовок

---

## Архитектурный подход

Архитектура проекта intentionally упрощена для ускорения разработки в условиях геймджема.

Игровая логика разделена на несколько управляющих систем:

* `FishingMinigame`
* `BoxingMinigame`
* `ShopManager`
* `DayManager`

ScriptableObjects используются для хранения данных:

* конфигураций рыб
* данных мини-квестов, влияющих на концовку

Такой подход позволил быстро изменять игровые параметры и добавлять новый контент без изменения основной логики.

## Технические задачи

### Система мини-квестов

При поимке особых рыб игрок может получить уникальные задания.
Квесты могут требовать:

* покупки особых предметов
* поимки определённого количества рыб

Прогресс выполнения квестов отслеживается на протяжении всей игровой сессии и влияет на финальную концовку.

### Система кошелька

Логика кошелька была разделена на:

* **model** — хранение и изменение значения валюты
* **view** — отображение UI

Это позволило использовать одну и ту же систему кошелька в разных сценах без дублирования логики.

## Особенности разработки

В проекте основной упор был сделан на **ощущение от взаимодействия игрока с механиками**.

Например:

* при победе в тайминговой мини-игре появляется надпись **K.O.**
* проигрывается ударный звуковой эффект
* фоновая музыка плавно затухает

Такие элементы усиливают импакт действий игрока и делают геймплей более выразительным.
